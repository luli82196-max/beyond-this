# Beyond This — Demo Capture Spec

## Recording master

- Canvas: 1920×1080, 16:9, 30 fps, H.264 MP4, 12–20 Mbps.
- Browser: production URL or local production preview; hide browser chrome, pointer, notifications and debug UI.
- Audio: enable sound before Forest; capture system audio in stereo at 48 kHz. Do not add BGM.
- Movement: use measured wheel/trackpad gestures; pause after each chapter settles. Record a clean master, then edit.
- Filenames: `beyond-this-quick-demo-30s-v1.mp4` and `beyond-this-walkthrough-3m-v1.mp4`.

| Time | Picture and action | Audio / text |

| 00:13–00:18 | Room wide frame, briefly reveal the three entries | Small caption: `BOOK · PROCESS · PROJECTION` |
| 00:18–00:23 | Open Projection, show a clean moving frame | Use production media sound only if present; otherwise silence |
| 00:23–00:26 | Cut to Book open, one page turn if stable | No extra sound design |

Operation path: Home → sound on → Forest → Tree transition → Room → Projection → close → Book → close → Light. Use straight cuts only where the continuous route would exceed 30 seconds.

## Three-minute walkthrough

| Time | Coverage |
| --- | --- |
| 00:00–00:20 | Home: title, concept line, input cue; enable sound deliberately |
| 00:20–00:55 | Seed: allow the opening statement and growth cue to settle |
| 00:55–01:25 | Forest: canopy, relation text and audible two-layer ambience |
| 01:25–01:45 | Tree: show material continuity and the symmetric sound fade |
| 01:45–02:35 | Room: wide frame, then Book, Process and Projection; close each and return to Room |
| 02:35–02:55 | Light: enter the final grade, hold the ending statement |
| 02:55–03:00 | End card: title and production URL |

Default is no voice-over. If narration is required, keep it to chapter intent and design decisions rather than describing visible actions. Suggested subtitles: chapter names, `sound on`, the three Room entry names, and the final URL. Capture one second of handles before and after every edit point.
