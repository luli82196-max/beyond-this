## About this release

《不止于此 · Beyond This》是一件关于跨领域学习，以及观看与创造如何彼此发生的五幕浏览器交互作品。

体验从 Seed、Forest 与 Tree 展开，在 Room 中通过 Book、Process 与 Projection 呈现同一作品的成品、创作判断与时间性观看，最后在 Light 中收束。它支持滚轮、触控与键盘输入，并包含减少动态效果、WebGL 静态降级及明确的媒体生命周期边界。

## Included in v1.0

- Complete Seed / Forest / Tree / Room / Light experience.
- BT-P03 Book / Process / Projection presentation surfaces.
- Responsive input, reduced-motion behavior, WebGL fallback, and Projection media lifecycle handling.
- Production deployment, metadata, device, Motion, and rollback acceptance recorded against the release identified above.
