# Beyond This — Portfolio Copy & Interview Package

## 中文简介（50–80 字）

《不止于此》是一件五幕浏览器交互影像作品。我以导演式节奏组织实时场景、光线、声音与滚动，让跨领域学习不再是技能清单，而成为观看、创造与生活之间持续生长的关系。

## English introduction

**Beyond This** is a five-act interactive digital film built for the browser. It uses real-time scenes, light, spatial interaction and restrained sound to frame cross-disciplinary learning as a relationship between seeing, making and living—not as a catalogue of skills. Technology functions as a directing medium: it shapes attention, rhythm and the continuity between each act.

## Three creative highlights

1. 用 Seed / Forest / Tree / Room / Light 的五幕结构代替常规作品列表，以章节节奏传达创作观。
2. 让暖色、暮蓝、木质材料和光线变化承担叙事，而非依赖解释性文字。
3. 将 BT-P03 的 Book、Process、Projection 收进同一生活空间，使成果、过程与观看方式彼此关联。

## Three technical highlights

1. 用统一章节时间轴解释滚轮、触控、键盘及正反向浏览，并在 Room 边界提供可感知的 detent。
2. 将 Three.js 场景、内容 presentation、媒体 ownership 与音频 runtime 分离，保证打开、关闭、重开和降级路径稳定。
3. Forest 音频按需创建，以 crossfade 循环、渐变增益与可见性生命周期减少突变和无效请求。

## 30-second interview introduction

“Beyond This 是我把作品集做成五幕交互影像的一次尝试。它不是用页面罗列技能，而是从 Seed 到 Light，用实时场景、光线、声音和滚动建立观看节奏。Room 里再把一件跨媒介项目拆成 Book、Process 和 Projection。技术在这里不是主角，而是我的导演工具：控制注意力、节奏和章节之间的连续性。”

## Three-minute interview structure

1. **0:00–0:35 / Why** — 说明为什么拒绝常规卡片式作品集，以及“跨领域学习是关系而非清单”的核心命题。
2. **0:35–1:20 / Directing system** — 讲五幕结构、色彩与光线系统、滚动节奏，以及声音为何只在 Forest 出现。
3. **1:20–2:05 / Room and BT-P03** — 演示 Book / Process / Projection，解释成果、方法和动态表达如何共享同一空间。
4. **2:05–2:40 / Engineering choices** — 讲统一时间轴、输入一致性、媒体 ownership、按需音频、reduced motion 与移动端。
5. **2:40–3:00 / Reflection** — 总结 AI 与实时技术如何参与探索和制作，同时由创作判断决定取舍；以 Light 的回望结束。
